# PTZ driver board

A driver board for PTZ camera heads and its firmware, designed together: one print that can drive any head.

## Status
Rev A of the board is designed and checked, but not ordered: five boards would cost almost €400.
Rev B is being specified: a cheap board for plug-in drivers, MCU and Ethernet, at most €100 per order.
Rev A stays in `hardware/` as reference. There is no firmware yet. The test rig for the mechanics is modelled, not printed.
Plan in `BACKLOG.md`, handoff in `STATE.md`, decisions in `DECISIONS.md`.

## What works today
- `hardware/`: the KiCad 10 project of Rev A, generated by the scripts in `hardware/tools/`, with BOM, placement file
  and Gerbers for JLCPCB in `hardware/fab/`. How to rebuild it: `hardware/README.md`.
- Checks that run on any machine with KiCad 10: `hardware/check_netlist.py` (every pin against the specs),
  `hardware/check_board.py` (every number in `specs/modules/board.md`, ERC and DRC), `hardware/check_fit.py`
  (the board with its plugs in the base).
- `tests/hardware/bringup-rev-a.md`: the current-limited first power-up, for the owner to run on the real board.
- `mechanica/rig/`: the test rig model and its checks.

## How work happens
Spec → test → build → review, one build per PR; see `CLAUDE.md`.
