# PTZ driver board

A driver board for PTZ camera heads and its firmware, designed together: one print that can drive any head.

## Status
Rev B of the board is designed and checked, and ready for a JLC quote: a cheap two-layer carrier for plug-in
drivers, MCU and Ethernet, estimated at €62 to €78 for five assembled boards. It is not ordered and not measured.
Rev A, which would have cost almost €400, is under the git tag `rev-a`. There is no firmware yet.
The test rig for the mechanics is modelled, not printed.
Plan in `BACKLOG.md`, handoff in `STATE.md`, decisions in `DECISIONS.md`.

## What works today
- `hardware/`: the KiCad 10 project of Rev B, generated by the scripts in `hardware/tools/`, with BOM, placement file
  and Gerbers for JLCPCB in `hardware/fab/`. How to rebuild it: `hardware/README.md`. What to buy and solder:
  `hardware/ASSEMBLY.md`.
- Checks that run on any machine with KiCad 10: `hardware/check_netlist.py` (every pin against the specs),
  `hardware/check_board.py` (every number in `specs/modules/board.md`, ERC and DRC), `hardware/check_fit.py`
  (the board with its modules and plugs in the base).
- `hardware/calc/`: the power calculations and the cost estimate of one JLC order, from the real BOM.
- `tests/hardware/bringup-rev-b.md`: the current-limited first power-up, for the owner to run on the real board.
- `mechanica/rig/`: the test rig model and its checks.

## How work happens
Spec → test → build → review, one build per PR; see `CLAUDE.md`.
